## How to Add New Concepts

When you learn something new:

1. **Create the Go file**: Add to `examples/` with a numbered prefix
2. **Write the wiki page**: Create in `concepts/` with the same number
3. **Include your questions**: Add the actual questions you asked
4. **Document the answers**: Include detailed explanations
5. **Add code references**: Link to specific lines in your examples
6. **Update this index**: Add the new concept to the list above
